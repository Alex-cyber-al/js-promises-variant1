# js-promises-variant1

Практична робота 10.1: Promises та ланцюжки промісів  
Варіант 1: Система замовлення їжі

## Опис проєкту

Цей проєкт демонструє роботу з нативними Promise у JavaScript без використання async/await.

Програма імітує обробку замовлення їжі через послідовний ланцюжок промісів:

1. Перевірка наявності товарів.
2. Резервування товарів.
3. Обробка оплати.
4. Планування доставки.

На кожному етапі є випадкова можливість помилки з шансом 20%.

## Використані технології

- JavaScript
- Node.js
- Native Promise
- .then()
- .catch()
- .finally()

## Як запустити проєкт

1. Відкрити папку проєкту у VS Code.
2. Відкрити термінал.
3. Виконати команду:

```bash
node app.js
```

## Очікуваний результат

Якщо всі етапи виконалися успішно, у консолі буде показано:

- перевірку наявності товарів;
- резервування;
- оплату;
- планування доставки;
- фінальне повідомлення про успішне замовлення.

Якщо на якомусь етапі виникне помилка, програма перейде в блок `.catch()` і покаже повідомлення про помилку.
